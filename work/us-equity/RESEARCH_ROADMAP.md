# Paperbot 研究路线

研究代码与模拟执行分别运行。研究输出需要独立验证后才能进入模拟策略验收。

| 阶段 | 交付与验收 |
| --- | --- |
| 行情与数据质量 | 记录数据来源、交易日历、采样和缺失原因。用带时间戳的快照验证输入可重放 |
| 基线与成本 | 先建立简单量化基线。按时间切分训练、验证和测试数据，纳入点差、滑点和流动性约束 |
| 候选策略 | 比较 HMM、GARCH、分类器与漂移检测的独立研究结果。冻结样本区间、特征和比较指标，保留未参与调参的样本 |
| 影子观察 | 用持续到达的行情记录候选输出。对同一评价窗口报告扣除成本的收益、回撤、换手率与不同市场状态下的表现 |
| 模拟策略验收 | 验证订单状态、重复执行保护、异常恢复与资金对账。按预设验收条件决定是否更换模拟策略 |

HMM 和 GARCH 的研究公式见 [候选模型设计](docs/R2_CHALLENGERS_PLAN.md)。点时股票池、公司行动、退市数据与更广的行情覆盖仍是扩大研究范围的前置条件。
